# VexBot Formation Helper Kit

This is a small Java helper project for formation calculations and a simple jump-decision helper.

IMPORTANT: This project is not integrated into VexBot 3.1.15 and is not an installable VexBot mod. It builds a standalone helper JAR only.

## Build
Requires Java 21 and Gradle:
gradle build

The GitHub Actions workflow builds the project and uploads the JAR as an artifact.
